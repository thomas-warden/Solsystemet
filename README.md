# Solsystemet downloadable app

Download Solsystemet.html using GitHub's Download raw file button, save it, and open it in Chrome or Edge on a computer. Sign in to your GitHub account first because this repository is private.

This updated 24 MB file includes all planets, moons, missions, orbital scenes, asteroid flight, and credits. It uses the existing standard-resolution planet textures to reduce memory use. All application assets are embedded. WebGL2 is required for interactive graphics.

Source: 8a48d9454e8bf41c1f7afbf0762d3b17b110add6 on codex/guided-exploration.

If a phone attachment preview stays on the loading screen, save the file and open it with a full browser on a computer. For viewing directly on a phone, enable the prepared gh-pages branch in repository Pages settings.
