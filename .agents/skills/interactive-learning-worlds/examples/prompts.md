# Example requests

## Dinosaurs

Use $interactive-learning-worlds to create a dinosaur explorer for ages 8–10. Build three short missions around body size, fossil clues, and which animals lived in the same period. Use sourced size ranges, accessible controls, and a working local preview. Clearly label reconstructions and uncertain anatomy.

## Periodic table

Use $interactive-learning-worlds to build an interactive periodic table for ages 10–12. Help learners connect element families and atomic structure to materials they know. Choose representations that explain the relationships clearly, include three guided missions, and source all element data.

## Culture atlas

Use $interactive-learning-worlds to build a cultural atlas for ages 8–10 exploring three named cities and communities. Include local voices, contemporary everyday life, language, food, and architecture with place and time context. Build missions around noticing and connecting evidence rather than matching national stereotypes.

## Machine museum

Use $interactive-learning-worlds to make an interactive museum of historical civilian and military aircraft for ages 9–12. Focus on how lift, propulsion, structure, and historical purpose influenced their designs. Include sourced specifications, cutaways and comparisons, and three engineering discovery missions.

## Ocean exploration

Use $interactive-learning-worlds to create a journey through ocean depth zones for ages 8–10. Let learners compare light, pressure, and adaptations, and complete three observation-based missions. Distinguish observed organisms and environments from illustrative layouts and scale changes.

## Improve an existing app

Use $interactive-learning-worlds to review this app for ages 8–10. Check the first useful action, clarity of its missions, phone layouts, keyboard access, reduced motion, loading failures, and animated labels over time. Implement the concrete findings and report what was verified.
